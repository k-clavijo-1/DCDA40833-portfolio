Lab 6: Interactive Hometown Map

Lab Overview

In this lab, I created an interactive hometown map that combines personal storytelling, design choices, and mapping tools. The goal of the assignment was to build a map that was both functional and meaningful by geocoding locations, customizing the basemap, and presenting places from my hometown of Quito, Ecuador in an interactive way. This lab focused on both the technical process of building the map and the design decisions behind how the information was presented.

Interactive Hometown Map

This map highlights several restaurants and places that represent my hometown of Quito, Ecuador. Each location includes a short description and an image so that users can explore the places in a more visual and interactive way.

Lab 6 Reflection

Design Inspiration

In the case of my custom basemap, I preferred that the map was not too bright or detailed. I used earthly colors as they are colors that I associate with the sceneries surrounding Quito, Ecuador. Having grown up there I would identify the environment with dull greens, warm brown and natural textures, and therefore, I attempted to capture the same in both the land and water colors of the map. I did not change the default Mapbox style, but instead I had to change various layers to make the color palette less aggressive and more unified. I also attempted to make the map as sparse as possible, to ensure that there is no overabundance of visual elements in the map.

Cartographic Challenges

One of the problems that I encountered during the map design process was ensuring that it was functional at various zoom levels. Depending on the number of roads, labels and details, the map was soon to become intimidating. I needed to consider what information was to be visible when the users are zoomed out as compared to when they zoom in on a closer view of the city. I used less detail at some lower zoom so that the map remained legible. I had to enable more information to come out at greater zoom levels to enable individuals to have a closer look at certain neighborhoods. The process allowed me to realize how cartographers determine which information to consider at various scales.

Technical Challenges

The technical side of this project involved working with Python and Folium to generate the interactive map. One of the main steps was geocoding the restaurant addresses so they could be converted into latitude and longitude coordinates. Some of the addresses initially returned incorrect or duplicate locations, so I had to adjust how they were formatted in the CSV file. I also had to connect my custom Mapbox style to the Python script so the basemap would load correctly. Troubleshooting the API requests and verifying that the Mapbox token was working took some time, but it helped me better understand how mapping tools interact with external services. Overall, this lab helped me see how design decisions and coding work together to create an interactive map.

What I learned and Skills Demonstrated

This lab demonstrates my ability to combine technical tools with design and personal storytelling. It shows that I can work with mapping platforms, geocode locations, troubleshoot technical issues, and think carefully about how users will interact with a digital project. It also helped me build stronger skills in spatial thinking, visual communication, and organizing information in an interactive format.
