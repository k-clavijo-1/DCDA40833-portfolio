Lab 6: Interactive Hometown Map

Interactive Hometown Map

This map highlights several restaurants and places that represent my hometown of Quito, Ecuador. Each location includes a short description and an image so that users can explore the places in a more visual and interactive way.

Lab 6 Reflection

Design Inspiration

For my custom basemap, I wanted the map to feel simple and calm rather than overly bright or busy. I chose earthy colors because they remind me of the landscapes around Quito, Ecuador. Growing up there, I associate the environment with muted greens, warm browns, and natural textures, so I tried to reflect that feeling in the land and water colors of the map. Instead of keeping the default Mapbox style, I adjusted different layers to create a softer color palette that felt more cohesive. I also tried to keep the map minimal so the markers and locations would stand out without too much visual clutter.

Cartographic Challenges

One challenge I faced while designing the map was making sure it worked well at different zoom levels. When too many roads, labels, and details appeared at once, the map quickly started to feel overwhelming. I had to think about what information should be visible when users are zoomed out versus when they zoom in closer to the city. At lower zoom levels I reduced the amount of detail so the map stayed readable. At higher zoom levels I allowed more information to appear so users could explore specific neighborhoods more clearly. This process helped me understand how cartographers decide what information is important at different scales.

Technical Challenges

The technical side of this project involved working with Python and Folium to generate the interactive map. One of the main steps was geocoding the restaurant addresses so they could be converted into latitude and longitude coordinates. Some of the addresses initially returned incorrect or duplicate locations, so I had to adjust how they were formatted in the CSV file. I also had to connect my custom Mapbox style to the Python script so the basemap would load correctly. Troubleshooting the API requests and verifying that the Mapbox token was working took some time, but it helped me better understand how mapping tools interact with external services. Overall, this lab helped me see how design decisions and coding work together to create an interactive map.
