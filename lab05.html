Lab 5: Vibe Coding & AI-Assisted Development

Feature Overview

I used AI assistance to implement a dark mode toggle using HTML, CSS, and JavaScript. This will provide users with an option of light and dark themes, which will be convenient to use.

AI Collaboration

The first structure was created by AI concerning the toggle and JavaScript logic. I checked the code line by line, commented and changed colors and layout. to be comparable to my current portfolio construction. Another application of AI that I did was as a debugging tool. the feature did not fit well initially with my existing CSS and layout, which assisted me in detecting and resolving the problems with style and structure.

AI Prompt Used

The following prompt was used to guide the AI when generating the initial dark mode toggle feature: 

Help me add a dark mode toggle to my HTML portfolio page.
Requirements:
- a button that toggles dark mode on/off
- use a CSS class like .dark-mode
- save preference with localStorage so it persists after refresh
- keep code beginner-friendly
- include comments explaining what each part does

Understanding Spectrum

The code includes comments that reflect my level of understanding, ranging from “I wrote this” to “I understand the logic but not the syntax yet.” These remarks are records of the points on which I had confidence in the execution and where. I used AI descriptions to get further insights.

My AI Use Guidelines

  • I use AI to generate starting points, not final answers
  • I do not commit a code I cannot explain
  • I review and comment on all AI-generated code
